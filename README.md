# HAMK physics and electrical engineering courses

Free, self-study interactive courses from HAMK: Theoretical Electrical Engineering **DC** and **AC**, and Physics 2
**Fluids, Heat and Thermodynamics**. Theory, live diagrams, simulators, quizzes, in English and Finnish.

**Open the courses: https://hamk-vlk.github.io/physics-courses/**

- DC circuits: https://hamk-vlk.github.io/physics-courses/dc/
- AC circuits: https://hamk-vlk.github.io/physics-courses/ac/
- Fluids, heat and thermodynamics: https://hamk-vlk.github.io/physics-courses/thermo/

## Privacy
- No accounts, cookies, analytics or tracking.
- Your progress is saved only in your own browser. Nothing is sent to HAMK, GitHub or anyone else. The pages'
  Content-Security-Policy forbids the browser from making any network request.
- To move your work to another device, save the notes file `student-notes.js` in the notes panel and load it there.
- The site is hosted by GitHub Pages, which, like any web host, logs visitors' IP addresses
  ([GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)).

## Use it offline
**Code → Download ZIP**, unzip, and open `dc/index.html`, `ac/index.html` or `thermo/index.html` in Chrome, Edge, Firefox or Safari.
